# E-Commerce Project

A full-stack e-commerce application built with React and Node.js.

## Features
- View a list of products.
- Add items to the shopping cart.
- Responsive user interface.

## Tech Stack
- **Frontend:** React.js
- **Backend:** Node.js, Express.js
- **Styling:** CSS
